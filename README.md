# Mad Libs Game

A fun and interactive **Mad Libs Story Generator** built with **Python and Streamlit**.

Choose a story, enter the requested words and let the application generate a funny and customized story based on your inputs.

---

## Features

- Multiple Mad Libs story templates
- Interactive web-based interface
- User-friendly input fields
- Generates customized and funny stories
- Deployed and accessible online
- Built entirely with Python
- Easy to use without installing Python or any dependencies

## Deployment

This project is deployed using **Streamlit Community Cloud**.

### Deployment Steps

1. Push the project to a GitHub repository.
2. Make sure `main.py` and `requirements.txt` are present.
3. Select the repository.
4. Select the `main` branch.
5. Set `main.py` as the application file.
6. Deploy the application.

The deployed application is available at:

👉 **[https://matlib-games.streamlit.app/](https://matlib-games.streamlit.app/)**

### Current Version – Streamlit

The project was later converted into a web application using Streamlit:

```text
Python
   ↓
Streamlit
   ↓
Web Interface
   ↓
User Input
   ↓
Generated Story
   ↓
🌐 Deployed Online
```

This makes the application accessible from any device with a web browser without requiring users to install Python.
