# 🎭 Mad Libs Game

A fun and simple **Mad Libs Generator** built with **Python and Tkinter**.

This beginner-friendly project allows users to choose a story, enter different types of words and generate a funny customized story based on their inputs.

---

## ✨ Features

- 🖥️ Simple graphical user interface using Tkinter
- 📖 Multiple Mad Libs story options
- 🔘 Interactive buttons for selecting stories
- ⌨️ User input for different word types
- 😂 Generates a customized and funny story

---

## 🛠️ Technologies Used

- **Python 3**
- **Tkinter** – Python's built-in library for creating graphical user interfaces

## 🚀 How to Run

### 1. Make Sure Python Is Installed

Check whether Python is installed on your system:

```bash
python --version
```

If that does not work, try:

```bash
python3 --version
```

If Python is not installed, download and install Python first.

> **Note:** Tkinter is included with standard Python installations on most systems. You do not normally need to install Tkinter separately using `pip`.

### 2. Clone the Repository

Clone this repository to your computer:

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY-NAME.git
```

Replace `YOUR-USERNAME` and `YOUR-REPOSITORY-NAME` with the actual GitHub username and repository name.

For example:

```bash
git clone https://github.com/Anvesha/MadLibs-Game.git
```

### 3. Open the Project Folder

Move into the project directory:

```bash
cd MadLibs Game
```

Open the project in VS Code:

```bash
code .
```

You can also open the folder manually using **File → Open Folder** in VS Code.

### 4. Run the Program

Open the VS Code terminal and run:

```bash
python main.py
```

A Tkinter window will appear with the available Mad Libs story options.

> **Important:** If the program uses `input()` to collect words, run it using **Run Python File** or `python main.py` in the Terminal. Do not use the Code Runner **Output** panel because the Output panel is read-only and cannot accept keyboard input.

---

## 🎮 How to Play

1. Run `main.py`.
2. The Mad Libs Generator window will open.
3. Choose one of the available story options.
4. Enter the requested words in the terminal.
5. The program uses your answers to generate a customized story.
6. Read and enjoy your funny story! 😂

---

## 📝 Example

### Sample Inputs

```text
Profession: doctor
Piece of cloth: shirt
Thing: bottle
Name: Pratham
Place: Mangalore
Verb ending in -ing: dancing
Food: chocolate
```

### Sample Output

```text
Say chocolate, the photographer said as the camera flashed!

Pratham and I had gone to Mangalore to get our photos taken on my birthday.

The first photo we really wanted was a picture of us dressed as cats pretending to be a doctor.

When we saw the second photo, it was exactly what I wanted.

We both looked like bottle wearing shirt and dancing -- exactly what I had in mind.
```

The generated story changes depending on the words entered by the player.

## 🛠️ Create Your Own Version

Want to customize the game and create your own Mad Libs?

You can either **fork this repository** or **clone it and create a completely separate repository**.

### Fork the Repository

Forking creates your own copy of this project on GitHub.

1. Click the **Fork** button at the top-right of this repository.
2. Select your GitHub account.
3. Open your newly forked repository.
4. Click **Code** and copy the repository URL.
5. Clone your fork:

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-FORKED-REPOSITORY.git
```

6. Move into the project folder:

```bash
cd YOUR-FORKED-REPOSITORY
```

7. Open it in VS Code:

```bash
code .
```

8. Modify `main.py` and create your own stories, design and features.
